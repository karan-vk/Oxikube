# Every container image the kind integration suites and the cluster fixtures run.
#
# One image per line; `#` starts a comment. This file is the single list:
#   - `cargo xtask kind-up` pulls each entry into every node (`crictl pull`), so no test waits on
#     a registry and none relies on an image that merely happens to be cached on a developer's
#     long-lived cluster;
#   - `oxikube_testkit::images` names the entries for the tests, and a test fails when an
#     integration test or a cluster fixture uses an image that is not listed here.
# Images that must NOT be pullable (`*.invalid`, `does-not-exist`) are deliberately absent.
